# dsh-agent-md（全局人格版）

把 `<DSH_HOME>/AGENT.md` 注入 DSH 的系统提示，并在设置里提供一个**只编辑全局人格**的页面。
版式沿用 0.2.0（头部、生效横幅、文件条、编辑器、操作栏），内容只剩一份全局人格。

- 文件：`<DSH_HOME>/AGENT.md`（`DSH_HOME` 缺省 `~/.dsh`）
- 注入：始终开启，没有开关（删掉文件或清空内容即可停止注入）
- 生效：保存后**下一个回合**生效，不用重启
- 写法：Markdown；`<!-- -->` 注释不会进上下文；`{{x}}` 会自动降级成 `{x}`
- 空文件 / 只有注释 = 不注入任何内容
- 保存时先备份 `.bak`，再写临时文件后 rename，避免写一半留下空人格

## 界面

设置 → **虚拟人物**：

- 头部：标题「虚拟记忆」+ 说明（无开关，默认始终注入）
- 生效横幅：本会话当前生效的是哪份文件、多少字；右侧是「文本占用 / 2 MB」进度条 + 连接状态
- 编辑器：文件条（路径 + 上次改动）、正文、保存 / 打开原文件 / 重新载入

## 记忆（按时间存，分三档）

聊出来的记忆就存在 AGENT.md 末尾的 `## 记忆` 一节，一行一条：

```md
- 2026-10-28 13:20："他住宿舍，平时十一点断电"；
- 2026-10-28 13:20："他把下载改成了断点续传"^3；   ← 提过 3 次
- 2026-10-29 02:10："他周五周六凌晨一点断电"*；    ← 钉住，永不淘汰
```

- **她自己写总结**：每轮正文末尾留一行 `〔记〕…`（日记口吻），client 摘走 `POST /memory`，宿主补时间戳写进 `## 记忆`；`〔记〕` 没来时先用会话事件里用户真打的那句垫一行，等 `〔记〕` 到了原地替换，不重复记。
- **写不写看惊讶度**：跟已有的每条比字符二元组重合率（Dice ≥ 0.6 算同一件事）。不像就新起一行；像就并进原来那条——时间刷成现在、`^N` 加一、正文留更长的那版。不新增行，也不复制一份。
- **三档由文件自己长出来，不存字段**：行尾带 `*` 是 core（每轮无条件注入、永不淘汰）；带 `^N`（N ≥ 1）是 mid；其余是 edge。core 一开始是空的，要不要升全看人。
- **到 2 MB 上限时才忘**：删掉 20%、留 80%；从 edge 里挑时间最旧的先走，edge 不够才动 mid，core 一律不动。正文、标题、没有时间戳的内容一律不动。
- **删之前先快照**：快照落在同目录的 `snapshots/`，文件名带时间戳，只留最近 30 份。删是不可逆的，快照是唯一退路（`snapshotMemory`）。
- **注入**：钉住的先放，其余按时间从新到旧取，总量上限 200 条，最后按原文件顺序排回去。
- 同一轮重复的请求（页面重挂、反复轮询）不会重复写、也不会把命中次数刷上去。
- 写回时先备份 `.bak` 再原子写；模型是直接改文件还是走保存按钮都一样，注入前兜一次。

## 收尾语

收尾语由她**每轮现场想**：表面的话和内心的想法分开想、互不推导；闲聊时两条都写（正文 + `〔尾〕`），干活时只写心里那条，只有一件事值得说就只写一条（`〔尾〕一句心里话 （颜文字）`），client 半（`conversation.chat.turnTail`，order 11）从页面里把那句摘走、塞进费用行末尾，正文里不留痕迹；10 秒内没等到标记才退回宿主的词库兜底。原来的做法是
（order 11，排在 dsh-cost-meter 之后）渲染一句。

兜底词库只在没等到 `〔尾〕` 时用（宿主没重启、或这轮她自己没写）；池子里句式和表情用两套步长挑，撞上上一轮就往后挪一格。

**心情由宿主算，不顺着用户**（`lib/index.js` 的 `closingFor`）：

| 心情 | 触发 |
| --- | --- |
| `miss` | 距上一轮超过 6 小时 |
| `tired` | 本地时间 23 点–3 点 |
| `teasing` | 连聊 6 轮以上且间隔小于 3 分钟 |
| `annoyed` | 每第 7 轮固定闷一次 |
| `happy` / `calm` | 其余按 momentum 走 |

心情决定句子和颜文字，句尾一定带一个表情。`GET /api/agent-md/closing?session=` 返回；
宿主还没这版接口时前端退回本地几句（`FALLBACK`），不留空。

费用行是 `<details><summary>本轮费用 ≈ ¥0.0063</summary></details>`，「本轮费用」和金额常是同一个
文本节点，插不进文本内部，所以收尾语作为**费用行的最后一个子节点**追加，落在金额之后、同一行；
找不到费用行时才退化成自己一行灰字（`.am-tail-block`）。金额是异步回来的，用 `MutationObserver`
盯着，被挤到中间就挪回末尾。

## 接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/agent-md/state` | 路径、是否存在、上次改动、字数、正文、启用状态 |
| GET | `/api/agent-md/closing` | 本轮心情 + 收尾语 |
| POST | `/api/agent-md/save` | 写入全局人格（备份 + 原子写，上限 2 MB） |
| POST | `/api/agent-md/open` | 在资源管理器里定位文件或目录 |

## 自检

```powershell
node test.mjs
```

10 组断言：全局注入、注释剥离、模板变量降级、忽略项目目录里的 AGENT.md、接口注册、保存与备份、
state 接口、心情判定（困 / 软 / 嫌烦 / 闷）、设置页与收尾语插槽。

## 安装

以本地 link 装进 profile（`dependencies` 与 `dsh.profile.bundles` 都要有一行）。改 host 代码要重启 DSH；
只改 `lib/client.js` 刷新页面即可。
